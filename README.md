# SubnetDesk Helper · Deploy · Agent

هذه **النسخة المخصّصة التي يديرها حساب [Aysar94-prog](https://github.com/Aysar94-prog)**، وتشمل سورس Helper وDeploy وAgent وتعديلاتنا على الوصول عبر الشبكة المحلية. الفرع الرئيسي هو **`master`**.

[تصفّح السورس الحالي](https://github.com/Aysar94-prog/SubnetDesk/tree/master) · [دليل الإدارة والنشر](deployment/README.md) · [تنظيم مساحة العمل](docs/WORKSPACE_LAYOUT.md) · [简体中文](README.zh-CN.md)

## مكوّنات مشروعنا

| المكوّن | وظيفته | إعداد النسخة الحالي في السورس |
| --- | --- | --- |
| **Helper** | عميل التحكم والمساعدة عن بُعد مع سياسة Receiver-only | 1.4.7 · Build 125 |
| **Deploy** | لوحة إدارة الأجهزة والمخزون والمهام ونشر Helper وAgent | 1.10.1 · Build 125 |
| **Agent** | خدمة Windows لإدارة الأجهزة والجرد والتثبيت والتحديث | 1.7.0 |

هذه أرقام إعدادات البناء الموجودة في السورس. الإصلاحات الأحدث تحتاج إعادة بناء الحزم لتصل إلى الأجهزة.

## التعديلات المضمّنة

- الاتصال المباشر واكتشاف الأجهزة على الشبكات المحلية، مع فحص نطاقات الشبكة وتجميع الأجهزة.
- إدارة الأجهزة والمهام ونشر الحزم من لوحة Deploy.
- إعادة تطبيق Receiver-only عند تثبيت Helper أو إصلاحه أو تحديثه، مع الحفاظ على الهوية وبيانات الوصول المخزّنة.
- منع تغيير هوية المتصل أو نوع الجلسة أو وجهتها أثناء إعادة محاولة المصادقة.
- إصلاح إدخال الأحرف والأرقام في طرفية Windows.
- تضمين مكتبة `hbb_common` كمجلد سورس عادي داخل `libs/hbb_common/`؛ لا يلزم مستودع ثانٍ أو submodule.

## تنزيل السورس على جهاز آخر

```sh
git clone https://github.com/Aysar94-prog/SubnetDesk.git source
cd source
```

الأمر ينزّل فرع `master` الذي يحتوي تعديلاتنا. إذا كانت لديك نسخة سابقة، احفظ أي تعديلات محلية قبل تحديثها.

## السورس والأدوات والمخرجات

```text
SubnetDesk-Helper/
  source/       # هذا المستودع فقط
  tools/        # أدوات البناء والكاش والاختبارات المحلية
  outputs/
    new/        # الحزم الحالية المعتمدة
    old/        # الإصدارات التاريخية
```

هذا المستودع ينشر **السورس والاختبارات وسكربتات البناء**. الأدوات المثبّتة والكاش وحزم MSI/APK وملفات إعدادات الأجهزة وبيانات الدخول تبقى خارج الرفع.

**لا توجد حزم إصدار منشورة لهذا الحساب حتى الآن.** روابط تنزيل المشروع الأصلي لا تمثل حزم Helper وDeploy وAgent المخصّصة هنا. المخرجات المحلية المعتمدة محفوظة في `outputs/new/` على جهاز البناء.
